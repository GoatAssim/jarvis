    When
    Hold these until a time you choose (one time, not a repeat). They wait paused and start by themselves, as long as the hub daemon is running then. If the time can't be read, nothing is added and this form says so. Leave empty to start straight away.
    Not needed with a start time: those wait paused anyway.

    Tell me when it (just for these)
    Leave all unticked to use your settings. These work even if notifications are off overall.

    Several links are queued together as one batch you can fold up in the list. Name it here, or leave this empty.
